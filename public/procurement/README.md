# Procurement pack

Files here are listed for download on `/for-hospitals`, so a hospital's buyers
can set Findway up as a supplier without emailing anyone. A file is listed only
once it is here, under the exact name in `src/lib/billing/procurement.ts`:

| File | What it is |
| --- | --- |
| `supplier-details.pdf` | Company number, VAT number, registered address, contacts |
| `bank-letter.pdf` | Bank details on headed paper (supplier set-up forms ask for it) |
| `insurance.pdf` | Certificates: professional indemnity, public/product liability, cyber |
| `dtac.pdf` | The NHS Digital Technology Assessment Criteria, completed |
| `dcb0129-safety-case.pdf` | DCB0129 clinical safety case and hazard log, signed by your clinical safety officer |
| `dspt.pdf` | Your Data Security and Protection Toolkit status |
| `dpia-template.docx` | A data protection impact assessment, pre-filled for the hospital's DPO |
| `accessibility-statement.pdf` | WCAG 2.2 AA statement and test results |

This folder is public: do not put anything here you would not hand to any
buyer.
